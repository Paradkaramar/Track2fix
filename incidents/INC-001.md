## Observed Symptoms

- `POST /payments` requests for non-USD currency payments are returning HTTP 500.
- USD-only payments appear unaffected.
- Error responses contain only `{"detail": "Internal Server Error"}`.
- No application-level error message is surfaced to the caller.
- Failures are reproducible and consistent — not intermittent.

## User / Customer Impact

- Customers attempting to pay in non-base currencies are unable to complete transactions.
- Affected orders remain unpaid.
- No data loss confirmed at this time.
